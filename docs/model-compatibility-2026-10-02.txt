Model compatibility follow-up — 2 October 2026

The reported qwen3_5 error came from the model server pinning Transformers 4.57.2.
That pin also downgraded manually upgraded environments at the next server start.
The model server now pins Transformers 5.18.0, Accelerate 1.15.0 and Hugging Face
Hub 1.33.0. Existing CUDA PyTorch installations are retained. The Hub pin keeps the
tested dependency set compatible with Python 3.10 and older pip installers.

Model metadata is inspected before tokenizer or weight downloads. Config, tokenizer
and weights use the same repository revision; safetensors and built-in model code
remain required. Unsupported chat architectures receive a specific error. The loader
uses the checkpoint's saved precision, and nested text configurations supply their
context limit. The API still accepts text chat; this does not add image/video input.

Cloudflare/clef is a structured-decision model with a custom joint prediction head.
Its standard Transformers config describes its backbone, not that decision head.
Running the backbone alone would omit the advertised decision behavior. Repositories
containing both joint_head_config.json and joint_head.safetensors are rejected with
a decision-runner explanation before weights download. This patch does not implement
Clef's decision API or execute its repository Python.

Primary reference: https://huggingface.co/Cloudflare/clef
Checked Clef repository revision: 2f3de3dd85f379784083b0814d997ab627200f0c

Validation

- 14 model-server tests passed on Windows Python 3.12 and Linux Python 3.10.
- Four real Linux checkpoint tests passed with PyTorch 2.8.0 CPU. Tiny random Llama,
  Qwen3.5 text, Qwen3.5 multimodal and Qwen3.5 MoE checkpoints were saved as
  safetensors, loaded with the new libraries and generated tokens. Text logits
  matched the original weights exactly; bfloat16 precision was retained.
- A fresh Linux Python 3.10 environment using pip 22.0.2 installed the exact pinned
  dependency set successfully, passed pip check and passed all four checkpoint tests.
- Live Hugging Face metadata checks accepted Qwen/Qwen3.5-27B and TinyLlama, and
  rejected Cloudflare/clef with the decision-head explanation. No weights downloaded.
- Five Rust model-runner tests and locked Windows all-targets Cargo checking passed.
  The embedded Python startup command remains below the 32 KiB runtime limit.

The full Clef checkpoint and real GPU generation were not run in this follow-up.
No existing model environment, installed desktop app or published installer changed.
These source fixes require a rebuilt app/engine release before existing installations
receive them. Test helpers are retained in artifacts/model-compatibility-20261002.
