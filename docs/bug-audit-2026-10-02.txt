Yougori bug audit — 2 October 2026

Audited source: 1.0.4, based on d367f6a, with the fixes below.
This audit covers the available Windows x64 and Linux x64 hosts. It does not
claim that every possible hardware, operating system or application was tested.

Fixes

The managed-environment download address picker used the shutdown-only required
selection prompt, so Escape was ignored. It now uses the normal cancelable
picker. Real Linux PTY checks reproduced the old behavior and verified that the
patched CLI returns to its menu without publishing a link.

PC folder sharing could expose an unshared file through a hard link. Its file
operations also checked absolute paths before opening them, leaving operations
vulnerable to concurrent path replacement. The service now retains an opened
directory capability for the share's lifetime. Reads, writes, text replacement,
metadata, directory listings and WebDAV/download requests remain confined to
that directory. File data operations reject hard links and special files.
Internal relative symlinks remain usable when they stay inside the share.
Text replacement reads a bounded amount of previous content.

New HTTP regressions cover unshared hard links, replacement of the selected
folder's path, escaping symlinks, FIFOs, nested file editing and permissions.
These restrictions apply to PC folder sharing. Portable environment downloads
continue to preserve hard links inside the environment's own filesystem.

Two native integration fixtures were stale. The guest-window fixture now
provides the runtime manager required by get_platform_state and reports its
explicit error. The private-network fixture now verifies rejection of a whole
filesystem share, then tests an explicitly selected project folder. Both pass
without changing the product's permission boundaries.

Validation

- Browser: 191 of 191 tests passed in the final complete run. An earlier
  connection-form retry timeout passed four focused repeats and the final run;
  no product change was made for that transient failure.
- Frontend: 532 unit tests, ESLint and the production build passed.
- Node scripts: 174 passed initially; the two platform/process-dependent skips
  were separately exercised successfully with no skips in those focused runs.
- Rust backend: 309 Windows and 301 Linux tests passed. The explicitly ignored
  integrations were exercised separately where supported. Windows all-targets
  Cargo checking passed with the lockfile enforced.
- CLI: 206 unique Windows and 203 unique Linux tests passed; duplicate executions
  of the same test module by the two CLI aliases are not counted twice.
- Native integrations: 38 distinct cases passed after the fixture corrections.
  These cover real containers, microVMs and PC VMs; secure boot and repeated
  guest reboots; storage growth and reclamation; snapshots, backups, reset and
  recovery; private networking and revocation; live Internet permission changes;
  terminals, guest apps, native WebView2 rendering, credential-vault access and
  the installed Cloudflare helper using isolated test credentials/endpoints.
- Native Linux desktop: launched the extracted desktop package in its expected
  installation layout using a private mount namespace, Xvfb and a private HOME.
  A real Alpine container passed snapshot restoration and live storage growth;
  a real Alpine microVM retained files across restart. Test nodes were removed.
- Linux SSH helpers: 21 transport/file/model tests passed; the remaining FUSE
  mount test passed separately in a private mount namespace. Nine Linux database
  sync tests and the vault binary-relay test passed.
- Large database: copied a 541,081,600-byte SQLite database with 8,193 records,
  including committed data in an open WAL. Snapshot integrity, user_version,
  record baseline and progress reports were verified; the original stayed open.
- Vault: 28 tests passed. CUDA host library: 11 tests passed. Go agent race checks
  passed. Six bounded-process-runner regressions passed.
- Installer: the actual 1.0.4 Linux engine archive installed, started and safely
  reinstalled in a private HOME. Existing profiles, PATH entries and a personally
  edited skill were preserved. The live CLI update checker correctly found the
  1.0.4 preview download without installing it. Release preflight passed.
- npm audit reported zero known vulnerabilities.

Local evidence is retained under D:/Yougori-Releases/bug-audit-20261001-v1.0.4.
The consolidated audit-summary.json records final native results and references
the original failure logs as well as corrected runs.

Limits

macOS, a physical Raspberry Pi/ARM64 host, clean Windows installation in a new
OS account, paid cloud deployments and a real CUDA workload were not exercised
in this audit. Existing CUDA distributions and the installed desktop app were
left untouched. Linux engine-only Cargo tests supplement the real packaged
Linux desktop check. Installer and desktop-package checks use the existing 1.0.4
release; the source fixes above are not installed into that running release by
editing this checkout. A future binary release must include them and rerun its
package verification. Builds remain unsigned under the previously chosen policy.
