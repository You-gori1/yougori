FIXED IN THIS AUDIT
- Imported files no longer broaden private Unix permissions (0600 files / 0700
  directories). The cloud exporter and guest importer retain those restrictions.
- OAuth client metadata rejects controls/bidi characters that could spoof native
  vault consent text. Approval still controls protected actions.
- Vault broker now bundles a static Windows CRT; the bundler checks imports so a
  clean machine does not need an unbundled VCRUNTIME140.dll.
- Updated desktop/CUDA rustls lockfiles to 0.23.45 for RUSTSEC-2026-0285.
- Incompatible appliance backing images now block startup instead of archiving
  the only active disk, deleting older recovery disks, and silently replacing it
  with an empty disk. A failed integrity check also keeps the existing disk.
  This safeguard is not an automatic migration or recovery implementation.
- Project SSH identity paths containing spaces resolve relative to the project,
  while actual inline public keys remain intact.
- CUDA preflight uses the chosen storage drive and only applies to CUDA workloads.
- Late platform refreshes cannot resurrect deleted environment nodes.
- Background deletion does not lock the configuration of another environment;
  deletion errors remain associated with their original environment.
- Remote workspace action state uses the selected environment's key.
- Late log responses and stopped model-generation state no longer overwrite the
  current view or leave it permanently busy.
- Closing/reloading the walkthrough home page ends a locally-owned guide.
  Retry tests now follow its instruction to use the terminal icon after the
  workload starts; the normal node Start/Stop behavior is preserved.
- Fixed encoding artifacts in configuration/CLI UI.
- Updated stale UI/CLI tests to current labels, permission options, creation tabs,
  terminal location, and idempotent managed skill installation behavior.
- Release scripts validate the public CLI and Windows PATH hooks; Linux installed
  smoke tests launch the desktop executable. Source collection requires vault
  and embedded skill sources and detects omitted untracked release sources.
- Removed remaining dead documentation links identified by the packaging review.

RELEASE GATES STILL OPEN
1. The guest permission fixes were compiled into staged artifacts under
   build/release-audit-2026-09-22/runtime/{appliance,cuda}. They were not copied over
   the live development appliance backing image. Final packaging must use the
   reviewed rebuilt guest payloads and matching manifests. Native VM checks above
   used the currently bundled runtime, not these staged appliance bytes.
2. npm run compliance:check fails because the current appliance bytes differ from
   the reviewed evidence. Regenerate and review evidence/source coverage for the
   final payload; provide its matching source bundle. A passing integrity check
   is not a substitute for that review. Required new sources are still untracked
   and must be included in the release source manifest; no files were staged here.
3. Clean-machine signed Windows installation, PATH availability in a fresh shell,
   full app shutdown, uninstall, and upgrade/recovery need final-package testing.
   Current CLI/vault payloads checked in this audit are unsigned. macOS signing/
   notarization and Linux installer verification were not established.
4. Linux GTK's glib 0.18.5 has RUSTSEC-2024-0429. No direct affected iterator use was
   found, but transitive reachability is not proven absent. Remediation requires
   a compatible upstream/backport and Linux validation before Linux release.
5. Paid cloud-provider provisioning, external ChatGPT/Claude OAuth, Windows Hello,
   every GPU/driver combination, large model downloads and real public tunnels
   were not exhaustively exercised. Browser tests use isolated fixture adapters
   for these operations. No user credentials or paid resources were used.
